# Software engineering

Apply architectural design approach before starting implementing. 

Create documentation of architectural designs ADR with diagrams.

Use domains oriented design.

Use hexagonal architecture.

Justify decisions according to design approachs used.

Use java programming languaje.

## Testing

Create e2e tests using cucumber framework

## Running
